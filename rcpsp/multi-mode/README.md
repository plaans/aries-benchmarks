# Multi-Mode RCPSP 


It contains a subset of the instances from PSPLIB.


OptalCP is used as a reference solver for computing the optimal value. The file `optal.py` was taken from [optalcp-benchmarks](https://github.com/ScheduleOpt/optalcp-benchmarks/tree/main/benchmarks/mmrcpsp) and the only modification are to facilitate the generation of test data.
